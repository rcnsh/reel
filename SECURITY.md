# Security

reel runs locally: it renders project code you trust in a headless Chrome, and its servers (`reel dev`, `reel review`, the warm renderer) listen on 127.0.0.1 only. A project is code, so render only projects you would run.

To report a vulnerability, open a [private security advisory](https://github.com/rcnsh/reel/security/advisories/new) rather than a public issue. You can expect a reply within a week.
